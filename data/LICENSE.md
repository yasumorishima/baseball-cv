[Driveline OpenBiomechanics Project](https://github.com/drivelineresearch/openbiomechanics)
(https://openbiomechanics.org/):

- `data/raw/*.c3d`: unmodified OpenBiomechanics C3D files.
- `data/output/`: CSVs, images and animations computed from OpenBiomechanics data by the code in this repository.
